# semidesign

イメージセンサー（CIS）の画素づくりを目標にした、シリコンの製造工程シミュレータです。
作り方（レシピ）から画素の断面（2次元）を計算し、出来た画素の電気的な性質（センサー下・TG下のポテンシャル、ためられる電子の数、読み出し後に残る電子の数）まで評価します。
格子と計算部分は次元に依存しない作りで、同じコードで3次元も動きます。

人がUIから使うことも、Claudeなどのエージェントがコマンドやライブラリとして呼ぶことも想定しています。

## 使い方

```bash
pip install -e .
semidesign run examples/cis_photodiode_2d.toml            # 結果は out/cis_photodiode_2d/
semidesign run examples/cis_photodiode_2d.toml --json     # 要約をJSONで標準出力へ（エージェント向け）
```

出力フォルダの中身:

| ファイル | 中身 |
|---|---|
| `summary.json` | 工程ごとのパラメータ・計算時間・結果、不純物の総量、指定位置での接合（p型とn型の境目）の深さ |
| `result.npz` | 最終状態の配列（材料、各不純物の濃度、正味の濃度、注入ダメージ、座標） |
| `steps/step_XX.npz` | 各工程後の状態（UIで工程を戻して見る用） |
| `cross_section.png` | 断面図 |
| `pixel_potential.png` | （`[pixel]` があるとき）TGオフ・オンのポテンシャルの地図、電子の通り道、通り道に沿ったポテンシャル |
| `pixel.npz` | 同じくポテンシャルの配列 |

Pythonから:

```python
from semidesign import Grid, Simulation
sim = Simulation(Grid(lateral_nm=(1100,), depth_nm=3000, spacing_nm=10), substrate_dopant="B", substrate_conc=1e15)
sim.etch(2500, openings=[[0, 50], [1050, 1100]])
sim.oxidize(1050, 30, "dry")                 # 溝の側面にも酸化膜がつく
sim.deposit("oxide", 60); sim.planarize(0)
sim.implant("P", 1.5e12, 1200, openings=[[150, 950]])
sim.anneal(1000, 0.5)
print(sim.summary())
```

## 画素の評価（`[pixel]`）

レシピに次の節があると、工程の後に画素を評価します。

```toml
[pixel]
pd_at = [450, 800]     # フォトダイオード（PD）の中の1点 [x, 深さ] nm
fd_at = [1000, 40]     # フローティングディフュージョン（FD）の中の1点
tg_off_v = -1.0        # TGの電圧（オフ / オン）
tg_on_v = 2.8
fd_v = 2.8             # FDのリセット電圧
```

ポテンシャル（電子にとっての高さ。電子はポテンシャルの高い所に集まる）を、不純物の配置と電極の電圧から計算します（`electrostatics.py`）。そのうえで、場所の決め方に左右されないよう、地形の特徴として定義した量を出します（`pixel.py`）。

| 量 | 定義 |
|---|---|
| センサー下ポテンシャル | 空のPDのポテンシャルの最大値（電子が集まる谷底）。その位置を「ためる場所」とする |
| TG下の峠と壁の高さ | ためる場所からFDへ、シリコンの中を通るすべての道のうち、いちばん低い点がいちばん高い道を選ぶ。そのいちばん低い点が峠。壁の高さ = 谷底 − 峠 |
| ポケット（TGオン） | PDの各点について同じようにFDへの峠を求め、その点の方が峠より高ければ電子が閉じ込められる窪み |
| ためられる電子の数 | PDに電子を詰めていき、電子の準フェルミ準位がTGオフの峠に届く（FDへあふれ出す）か、基板に対して順方向になる（0 V）までの電子の数 |
| 読み出し後に残る電子 | TGオンで、PDの各点が自分の峠（またはFDの電圧）まで電子を吐き出した後に残る数 |

2次元では奥行き方向に同じ形が続くとみなすので、電子の数は「奥行き1 μmあたり」です。どれも準静的（時間をかけた後のつり合い）な評価で、有限の時間で読み出すときに残る数は、壁が熱エネルギーの数倍以上あるとこれより増えます。

## 座標と単位

- 配列は「横方向の軸 → 深さ方向の軸」の順（2次元: `(nx, nz)`、3次元: `(nx, ny, nz)`）
- 深さ 0 が最初のシリコン表面、上が負。表面より上に `headroom_nm` の余白を取り、酸化膜や堆積膜はそこに伸びる
- 長さ nm、濃度 cm⁻³、注入量 cm⁻²、温度 ℃、時間 分
- マスクの開口 `openings`: 2次元は `[[x0, x1], ...]`、3次元は `[[x0, x1, y0, y1], ...]`
- `periodic = true` で左右の端がつながる（画素が繰り返し並ぶ扱い）。既定は端で鏡写し
- 材料: `Si`, `oxide`, `poly`（ゲート電極）, `nitride`
- 格子: 基本の間隔 `spacing_nm` に加えて、`[[grid.refine]]` で軸ごとに細かくする帯を指定できる（`axis = "x" | "y" | "depth"`, `from_nm`, `to_nm`, `spacing_nm`）。隣り合うマスの大きさの比は `growth`（既定 1.3）以内に抑える。最初のシリコン表面（深さ0）は必ずマスの境目になる

## 工程

| 工程 | 内容 |
|---|---|
| `etch` | マスク開口部を真下に掘る（材料の指定も可。例: 窒化膜だけ除く） |
| `deposit` | 膜をつける。既定は形に沿ってつく（細い溝は埋まる） |
| `planarize` | 指定の高さより上を削って平らにする |
| `implant` | イオン注入。`rp_nm` / `drp_nm` / `lateral_sigma_nm` で実測（SIMS）に合わせられる。`damage_factor` で注入ダメージの量を調整 |
| `anneal` | 熱処理。拡散、注入ダメージによる一時的な加速、材料の境目での不純物の移動 |
| `oxidize` | 熱酸化。露出したシリコンのあらゆる面（溝の側面も）が酸化する。窒化膜がマスクになる |

## 物理モデル

モジュールは物理の単位で分かれています。

| モジュール | 担当 |
|---|---|
| `bca.py` | イオンを1個ずつ追うモンテカルロ計算で、注入イオンの止まる深さの分布表を作る |
| `implant.py` | 分布表から注入プロファイルを作る |
| `defects.py` | 注入ダメージと、それによる一時的な拡散の加速 |
| `diffusion.py` | 不純物の拡散と、材料の境目での移動 |
| `oxidation.py` | 多次元の熱酸化 |
| `dopants.py` / `materials.py` | 物性値 |
| `electrostatics.py` | ポテンシャル（ポアソン方程式、電子・正孔、ゲート電極） |
| `pixel.py` | PD・FDの特定、谷底・峠・通り道、電子の数 |
| `grid.py` | 場所ごとに間隔を変えられる格子 |
| `fv.py` | 上の計算が共通に使う、格子上の方程式の組み立てと解法 |
| `simulation.py` | 状態を持ち、工程ごとに上を呼ぶ。熱工程は酸化・ダメージ・拡散を一つの時間ループで進める |

### イオン注入（`bca.py`, `implant.py`）

- 深さ分布は、イオンを原子との衝突ごとに追うモンテカルロ計算（アモルファスSi、1点6000個）で 1 keV〜5 MeV について作り、`data/implant_ranges.json` に保存してある。分布の形そのもの（深い注入で表面側に伸びる裾を含む）を分位点で持ち、エネルギー間は分位点ごとに補間する
- 原子との衝突: ZBLの遮蔽ポテンシャルと MAGIC 式（Biersack & Haggmark 1980）
- 電子による減速: B は SRIM-2013 の表、P / As / Sb は Lindhard–Scharff の式
- 検証: B の平均深さは SRIM と 10 keV〜3 MeV で数%以内。広がりは SRIM の表より 10〜20% 狭く出る（SRIMの表は解析的な計算法による値）。P / As / Sb は Lindhard–Scharff 式の精度（±20%程度）に従う
- 表の作り直し: `python -m semidesign.bca`（2コアで十数分）

### 注入ダメージによる一時的な拡散の加速（`defects.py`）

- 注入されたイオン1個につき、余分なシリコン原子（格子間原子）が1個残る（"+1" モデル）。それらは塊になり、熱処理で時定数 τ で溶ける
- 溶け出した格子間原子は表面や酸化膜との境目で消える。その分布を毎ステップ解き、過剰の度合い S を求める
- B / P は S 倍近く速く拡散し、Sb は S が中程度なら遅くなる（`f_I S + (1 − f_I)/S`）
- 値: D_I C_I* は Bracht ら（1995）、塊が溶ける速さの温度依存は Eaglesham ら（1994、3.8 eV）。τ は 800℃で1000秒（900℃で約30秒、1000℃で約2秒）に設定。実際には注入量でも変わるので合わせ込み用の値として扱う
- 大量注入（As 1e15 など、結晶が壊れる量）では "+1" は過大評価になりやすい。`damage_factor` で調整する

### 熱酸化（`oxidation.py`）

- Deal–Groveモデルを面の問題として解く: 酸化剤が酸化膜中を拡散し、シリコンとの境目で反応する。平らなウェハでは Deal–Grove の式と1マス以内で一致
- 増えた体積は、酸化膜を流体とみなして表面へ押し出す。細い溝の中の酸化膜は上へあふれる
- 窒化膜は酸化剤を通さないのでマスクになり、端の下への回り込み（バーズビーク）も同じ式から出る
- 未対応: 応力、面ごとの結晶方位の違い（ウェハの方位を全面に使う）、薄いdry酸化の初期の速い成長

### 境目での不純物の移動（`diffusion.py`）

- シリコンと酸化膜の境目では、平衡で C_Si / C_SiO2 = m（B 0.3、P / As / Sb 10）
- 静止した境目: 拡散の式そのものに m を入れてあるので、時間をかければ自然にこの比になる
- 動く境目（酸化中）: シリコンが酸化膜に変わるたびに、その場で平衡に分け直す。P は境目のシリコン側にたまり、B はシリコン側から減る
- 酸化膜中の拡散係数: B は文献値、As / Sb は信頼できる値が見つからず P と同じにしている

### 電気の計算（`electrostatics.py`）

- ポアソン方程式をシリコン・酸化膜・窒化膜で解く。電子と正孔はボルツマン分布。正孔は接地した基板とつり合い、電子はPD内では指定の準位、それ以外はFDの電圧とつり合う（TGの下に開く通り道にはFDから電子が入るため）
- ゲート（多結晶シリコン）は電圧 + 0.56 V（n+ポリ）に固定
- 検証: pn接合の内蔵電位が理論値と一致、酸化膜とシリコンの境目で電束が連続
- 未対応: 高濃度での統計の補正、酸化膜中の固定電荷・界面準位、時間を追う電流の計算（電子の移動の速さ）

## まだ入っていないこと

- 高濃度で拡散が速くなる効果、不純物の電気的な活性化（塊になって働かない分）
- 結晶の向きに沿ってイオンが深く入る現象（チャネリング）、斜め注入
- 酸化膜や窒化膜の中でのイオンの止まり方の違い（すべてSiとして計算）
- 横方向の広がりの深さ依存（一定のガウス分布）
- 光の吸収の計算、時間を追う電気の計算（読み出しにかかる時間、残像の時間依存）
- TGの幅（断面と直角な方向）の影響。2次元では奥行きに無限に続く扱い。3次元で計算すれば入る

## 例のレシピについて

`examples/cis_photodiode_2d.toml` は、1.1 μm画素の断面（PD・TG・FD）の一例です。評価結果は、センサー下ポテンシャル約1.4 V、TGオフの壁約0.55 V、TGオンでためる場所から見た壁約0.25 V、ためられる電子 約430個/μm、読み出し後に残る電子 約1.6個/μm（いずれも準静的な見積もり）。
PDの不純物をTG側で強めると読み出しは良くなるが、ためられる数は減る、という典型的な設計の綱引きがそのまま現れます。合わせ込み前の値なので、実際の工程の値とは異なります。
