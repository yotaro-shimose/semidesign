# semidesign

イメージセンサー（CIS）の画素づくりを目標にした、シリコンの製造工程シミュレータです。
画素の断面（2次元）を計算します。格子と計算部分は次元に依存しない作りで、同じコードで3次元も動きます。

人がUIから使うことも、Claudeなどのエージェントがコマンドやライブラリとして呼ぶことも想定しています。

## 使い方

```bash
pip install -e .
semidesign run examples/cis_photodiode_2d.toml            # 結果は out/cis_photodiode_2d/
semidesign run examples/cis_photodiode_2d.toml --json     # 要約をJSONで標準出力へ（エージェント向け）
```

出力フォルダの中身:

| ファイル | 中身 |
|---|---|
| `summary.json` | 工程ごとのパラメータ・計算時間・結果、不純物の総量、指定した位置での接合（p型とn型の境目）の深さ |
| `result.npz` | 最終状態の配列（材料、各不純物の濃度、正味の濃度、座標） |
| `steps/step_XX.npz` | 各工程後の状態（UIで工程を戻して見る用） |
| `cross_section.png` | 断面図 |

Pythonから:

```python
from semidesign import Grid, Simulation
sim = Simulation(Grid(lateral_nm=(1100,), depth_nm=3000, spacing_nm=10), substrate_dopant="B", substrate_conc=1e15)
sim.etch(2500, openings=[[0, 50], [1050, 1100]])
sim.deposit("oxide", 60); sim.planarize(0)
sim.implant("P", 4e12, 200, openings=[[150, 950]])
sim.anneal(1000, 1)
print(sim.summary())
```

## 座標と単位

- 配列は「横方向の軸 → 深さ方向の軸」の順（2次元: `(nx, nz)`、3次元: `(nx, ny, nz)`）
- 深さ 0 が最初のシリコン表面、上が負。表面より上に `headroom_nm` の余白を取り、酸化膜や堆積膜はそこに伸びる
- 長さ nm、濃度 cm⁻³、注入量 cm⁻²、温度 ℃、時間 分
- マスクの開口 `openings`: 2次元は `[[x0, x1], ...]`、3次元は `[[x0, x1, y0, y1], ...]`
- `periodic = true` で左右の端がつながる（画素が繰り返し並ぶ扱い）。既定は端で鏡写し

## 工程

| 工程 | 内容 |
|---|---|
| `etch` | マスク開口部を真下に掘る（指定の深さ、材料の指定も可） |
| `deposit` | 膜をつける。既定は形に沿ってつく（溝の側面にもつくので細い溝は埋まる） |
| `planarize` | 指定の高さより上を削って平らにする |
| `implant` | イオン注入。深さ方向はガウス分布をマスごとに積分（量が正確に保存される）、横方向にもガウス分布で広がる |
| `anneal` | 熱処理による拡散。材料ごとに拡散の速さを変え（酸化膜ではほぼ止まる、気体へは出ない） |
| `oxidize` | 熱酸化（Deal–Grove）。各列で縦方向に成長し、増えた厚さの44%ぶんシリコンを消費。マスク下は酸化しない |

## 計算方法

- 格子: 等間隔の四角いマス。形状はマス単位（解像度＝格子間隔）
- 拡散: 陰的な時間積分。2次元（約40万マス以下）は連立方程式を直接解き、3次元など大きい場合は反復法に切り替えて記憶容量を抑える
- 目安: 1.1μm×3μmの断面を10nm格子（3.5万マス）で 熱処理約1秒、5nm格子（14万マス）で約5秒。3次元 20nm格子（48万マス）で約2秒

## まだ入っていないこと

- 高濃度で拡散が速くなる効果、注入ダメージによる拡散の加速
- 酸化膜とシリコンの境目での不純物の移動（現在は境目でほぼ止まるだけ）
- 溝の側面の酸化、マスク端の酸化の回り込み
- イオンを1個ずつ追う注入計算、ゲートなどの多結晶シリコンの形づくり
- 光の吸収と電気（電子の集まり方）の計算 ← 次の段階

範囲表は 10〜200 keV。それ以外のエネルギーは外挿で、`summary.json` に `range_extrapolated` として記録されます。
